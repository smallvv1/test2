# Soft Intrusion 漏检分析

运行：`20261021_085235`。仅使用 LTCC train-only 冻结 Bio/GPC 特征，未读取 query/gallery/test。

## 定义

P2：

`u=Q25(sim(anchor,P))`，`I_P2=mean_c sigmoid((sim(anchor,n_c)-u)/0.07)`。

候选负样本为固定的 reference 代表；current 不重新挑选关系。

危险标签为固定关系的 `reference_edge=min(P)-max(N)>0` 且 `current_edge<=0`。

## 漏检统计

| seed | 边界翻转 | P2 `Delta_I<=0` 漏检 | P5 `Delta<=0` 漏检 | P2 质量上升但边界翻转 | Q25 上升但边界翻转 |
|---:|---:|---:|---:|---:|---:|
|1234|47|34|35|13|12|
|4321|31|9|10|22|3|

因此 P2 平均风险下降并不能排除单个危险负身份越过边界。翻转行中，危险负样本数量合计分别为75和42；其余安全负身份的平均可能把一个局部灾难稀释掉。P2 还受 Q25 正样本阈值变化影响；sigmoid 在远离阈值的负样本上也容易饱和。每个负 PID 只保留一个代表还会丢失同一 PID 内的尾部信息。

## 结论

Soft Intrusion 适合做“多 PID 总体混淆”诊断，不适合单独作为局部边界保护门控。不能把 P2 的 endpoint 结果直接转成 P5 训练损失，也不能把一个平均风险下降解释为判别结构安全。任何后续机制必须同时审计关键边界和多身份总体量，并预注册风险规则。
