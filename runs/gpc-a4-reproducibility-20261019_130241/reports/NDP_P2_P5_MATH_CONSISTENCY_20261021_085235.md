# P2 / P5 数学一致性审计

## 两个实际定义

P2 使用逐负 PID 代表和正样本 Q25：

`I_P2 = (1/C) Σ_c sigmoid((v_c - Q25(P))/tau)`。

P5 `ndp_intrusion_loss.py` 使用集合级 log-mean-exp：

`I_P5 = sigmoid(LME(N/tau) - LME(P/tau))`，其中 `LME(X)=log(mean(exp(X)))`。

P5 的惩罚是 `relu(I_current-I_reference-epsilon)`。两者只有在特殊退化条件下才近似一致：正负集合大小、相似度分布和代表规则都必须足以使 Q25 与正集合 LME、负代表均值与负集合 LME 具有相同排序。一般情况下并不等价。

## 明确反例与单测

参考正样本为4个0.8、负样本为20个0.7；当前正样本为4个0.9，负样本为一个0.92和19个0.1。参考边界为正，当前边界翻转；但 P2 与 P5 都下降。该反例已加入 `test_ndp_risk_modules.py`，证明聚合风险不能替代关键边界标签。

因此：P2 不是 P5 的离线实现，P2 的 AUC/漏检不能支持 P5 的训练有效性；本轮不把两个损失相加，也不提出正式 NDP loss。
