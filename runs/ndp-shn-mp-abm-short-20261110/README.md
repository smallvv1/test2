# NDP SHN-MP ABM short runs

LTCC and PRCC 3-epoch short-run logs for the anchor-aware boundary-mining arm.
Each `SHORT_RUN_COMPLETE.json` records the completed step count and the SHA-256
of the excluded local model checkpoint.

The `model_final.pth` files are intentionally not committed because each is
approximately 1.2 GB. The code and reproducible run metadata are in `main`.
